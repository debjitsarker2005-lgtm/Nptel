2. The Naive Bayes classifier can produce a non-linear decision boundary, 
depending on the probability distributions assumed for the features. 
For example, in Gaussian Naive Bayes, the class-conditional probabilities are 
modeled using Gaussian distributions. When different classes have different 
variances, the resulting decision boundary can be quadratic (non-linear). 
3. Class Imbalance 
Explanation 
In One-vs-Rest (OvR) multi-class classification, a separate classifier is trained 
for each class: 
• Class 1 vs. all other classes  
• Class 2 vs. all other classes  
• Class 3 vs. all other classes  
• etc.  
This can create a class imbalance problem, because the positive class may 
contain far fewer samples than the combined negative classes. 
For example, with 5 classes having 100 samples each: 
• Class 1 → 100 positive vs. 400 negative  
• Class 2 → 100 positive vs. 400 negative
