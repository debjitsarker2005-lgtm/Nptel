9. The 1st statement is, ANN error surface has multiple local minima while SVM error 
surface has only one minimum. 
•  ANN training is generally non-convex, so it may have multiple local 
minima/saddle points.  
•  SVM optimization is a convex optimization problem, so it has a global optimum. 
So it is True. 
 

The 2nd statement is After training, an ANN might land on a different minimum each 
time when initialized with random weights. 
Different random initializations can lead gradient descent to different 
solutions/minima. 
So it is also True. 
Statement 3 is saying, Some classes of functions cannot be learned by an ANN. An 
SVM can learn a hyperplane for any kind of distribution.  
The limitation described applies to a single-layer perceptron, not neural networks in 
general. Also, a standard SVM learns a linear hyperplane; kernels can allow nonlinear 
decision boundaries, but not literally "any kind of distribution." It is False. 
 
The 4th Statement is, ANN uses gradient descent, while SVM uses convex 
optimization solvers. 
ANNs are commonly trained using gradient-based optimization such as 
backpropagation + gradient descent, whereas SVM training is formulated as a convex 
optimization problem. So it is True.
